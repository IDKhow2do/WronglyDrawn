# 错画之城 · Wrongly Drawn — 故事与角色设定

> 一句话：**一个孩子没画完的城市，被橡皮擦"改正"着；你是他画的最后一个涂鸦。**
> 这款游戏关于"画错"的权利——歪的房子、多出来的眼睛、不对称的腿，都是这座城的生命。

---

## 世界观

**画城（The Drawn City）** 是一个叫 **小米 (Mi)** 的孩子画在一张大画布上的城市。
他画得很快、很乱、很开心：房子是歪的，路灯长了眼睛，垃圾桶会咬人，每栋楼都有一张脸。
画布上的一切只要被"看见"，就是活的。

后来，大人说："画错了，擦掉重画吧。"
那天晚上，孩子放在桌角的 **橡皮擦** 醒了。它相信自己在"帮忙"——
它要把一切"画错"的东西改正：先擦掉城市的 **眼睛**（看不见的东西就不算存在），
再擦掉道路，最后擦掉整座城，只留下一张干净的白纸。

城市碎成一块块漂浮在颜料天空里的画布岛。第一块，就是 **盲眼广场 (Blind Plaza)**。

### 规则（同时也是玩法）
| 世界规则 | 玩法表现 |
|---|---|
| 被看见的东西才是真的 | 用"眼睛贴纸"看铅笔草图，草图就变成实体（桥、台阶、弹簧） |
| 颜料 = 生命 | 喷漆可以把被腐蚀的怪物"重新上色"，也能把灰色的东西画活 |
| 器官可以借出 | 眼睛、嘴巴、腿都是贴纸：贴到建筑、雕像、箱子上，它们就会醒来、说话、走路 |
| 橡皮屑会腐蚀 | 橡皮擦掉下的碎屑会变成怪物（橡皮虫），也能被你捡起来扔回去 |
| 掉出画布 = 被重新画一遍 | 不会死，只是被"重画"回最后一个喷漆罐的位置 |

## 主角

### WAI（"歪"）
- **身份**：小米睡前画的最后一个涂鸦。一个方盒子脑袋的小家伙，戴着歪王冠，披着红斗篷，拿着一罐喷漆。
- **名字**：小米写他名字时写歪了——"WAI"，就是"歪"。他很喜欢这个名字。
- **性格**：不说话，但很有态度。好奇、倔强、有点臭屁（王冠永远是歪的，他也不扶正）。
  他不知道自己"画得不标准"，所以也从不觉得自己需要被擦掉。
- **能力**：
  - 喷漆：把颜色还给世界
  - 投掷：几乎能举起、扔出身边的东西（箱子、桶、橡皮屑、甚至自己的喷漆罐）
  - 器官贴纸：把眼睛/嘴巴/腿贴给别人，借给它们"感官"
- **造型要点**：方头、王冠（巴斯奇亚式三尖冠）、红色方巾斗篷系在脖子上、红色高帮鞋。
  轮廓从俯视看是"方块 + 王冠环"——开场铅笔画的正是这个轮廓。
- **成长**：每关结束，小米会在他身上"多画一笔"（披风皮肤、火箭臂、大罐子…= 挑战奖励）。

### 小米 (Mi) —— 画画的孩子
- 只以"巨大的铅笔"和"画外的笔触声"出现。从不露脸。
- 每唤醒一位守护者，铅笔就会从天空伸下来，把被擦掉的路重新画上——**孩子在帮你**。
- 最终关的情感核心：孩子决定"不擦了，就这样"。

## 反派

### 橡皮擦 (THE ERASER)
- **外形**：一块巨大的粉色橡皮，皱着眉、咧着一口方牙，身上全是被磨出来的碎屑。
- **动机**：它不是坏，它是 **"正确"**。它真心认为歪的东西是错误，擦掉是在帮忙。
  它的台词都是老师口吻：
  - "不对。重画。"
  - "线歪了。"
  - "这里不该有眼睛。"
- **招式**（每招都有明确的应对）：
  | 招式 | 预兆 | 应对 |
  |---|---|---|
  | 搓地冲刺 RUB | 地面出现闪烁的粉色擦痕 | 侧闪（C）；贴身最后一刻闪避 → 颜料时间（慢动作） |
  | 碎屑雨 SHOWER | 跳起、张嘴 | 跑位躲开落点；碎屑落地变石头 → 捡起砸回它脸上 |
  | 重压 SLAM | 高跳 + 阴影 | 远离阴影，跳过冲击波环 |
  | 撞墙眩晕 DAZED | 冲刺撞到边缘 | 输出窗口！对脸喷漆伤害翻倍 |
- **阶段**：每掉三分之一血会暴怒（"它暴怒了！"），短暂无敌并换招式组合。
- **结局**：被重新上色后，它缩回一块小小的、普通的橡皮——被孩子捡起来放回了笔盒。
  它不再擦东西，只在画错时"轻轻地"帮忙。

### 被腐蚀的生物（橡皮屑寄生）
| 怪物 | 原本是 | 被腐蚀后 | 掉落 |
|---|---|---|---|
| **偷窥路灯** Peeping Lamp | 广场上照路的灯 | 眼睛被擦成冷光，发射"擦除光束" | 眼睛贴纸 |
| **咬咬垃圾桶** Chomper Bin | 码头边吃垃圾的桶 | 吃掉一切颜料再吐回来 | 嘴巴贴纸 |
| **歪腿怪** Crooked-Leg Mutant | 工地的搬运工 | 腿被擦歪，只会横冲直撞 | 腿贴纸 |
| **橡皮虫** Eraser Grub | 橡皮屑 | 到处啃颜料 | 颜料滴 |

被打败后它们不会消失，而是 **"重新上色"**：恢复原样、变得友好（路灯会给你照路）。

## 守护者（盲眼广场）

| 守护者 | 性格 | 需要 | 醒来后 |
|---|---|---|---|
| **瞌睡崖** Sleepy Cliff | 山崖上的巨脸，老爷爷，总在打盹 | 一只眼睛 | 看见运河 → 画出桥 + 第一段山路 |
| **门楼** Gatehouse | 堡垒上的嘴，话痨但被擦了嘴 | 一张嘴 | 大喊放下吊桥 + 第二段山路 |
| **盲眼雕像** Blind Statue | 广场中央，城市的建造者 | 一只眼睛 | 抬头望向塔 → 第三段山路 |

## 关卡故事节拍（第 1 关：盲眼广场）
1. **被画出来**：巨大的铅笔在码头上描出 WAI 的俯视轮廓，颜色涌入，他站起来。
   天空中橡皮擦呼啸而过，把整座城的眼睛擦掉，滚上山顶的塔。
2. **第一只眼**：起步路灯偷窥着你——把它重新上色，拿到第一只眼睛。
3. **三位守护者**：每唤醒一位，铅笔就重画一段山路（镜头演出）。
4. **登顶**：橡皮擦朝你扔碎屑——它们落地成了石头，捡起来，扔回去。
5. **决战**：山顶被橡皮屑封住，没有退路。三个阶段。
6. **城市睁眼**：所有建筑在一波浪潮中睁开眼睛。塔门打开，通往下一块画布。

## 后续关卡构想
- **第 2 关 · 无声码头 (Mute Harbor)**：橡皮擦掉了声音。嘴巴贴纸成为核心，靠"喊"来开机关。
- **第 3 关 · 瘸腿工厂 (Limp Works)**：一切都不会动了。腿贴纸 + 搬运谜题。
- **最终关 · 白纸 (The Blank Page)**：橡皮擦本体，和孩子的手。WAI 选择"保持歪"。

## 美术与语气
- 巴斯奇亚式王冠、毕加索式歪脸、厚涂涂鸦；粉 / 橙 / 钴蓝 / 青绿 / 黄。
- 不黑暗、不血腥：伤害 = 被擦淡（低血量画面褪色 → 黑白），死亡 = 被重画。
- 幽默来自"不正确"：多出来的眼睛、会打嗝的垃圾桶、王冠永远是歪的。
