**1. 核心评审**

**前三分钟：美术钩子强，玩法钩子出现得太晚。**

**器官系统：保留能力代价，减少操作成本。**

当前有三个会削弱探索动力的问题：

1. **主线绕开组合。**雕像只检查借出的 Eye，没有转向和清理脸部的前置条件。Gatehouse 借 Mouth 就开桥，没有实际吞咽障碍的过程。[苏醒条件](<local-path>)

3. **组合常常只是两个效果并列。**Eye 不参与 Mouth 的选敌；普通 Host 没有吐出行为；小 Eye 没有专门的秘密提示；瞄准地点命令也尚未实现。不能把设计稿中的全部组合当成现有能力。

**喷漆：让落在哪里、怎样留下来，比喷了多少更重要。**

当前已经有连续颜料流、世界笔迹和 Grub 擦除，并非只有枪械换皮。缺少的是**笔迹改变下一步决策**。

建议采用以下顺序：

- **先做“标记”。**喷在地面的新鲜颜料吸引附近 Grub；喷在 Host 上的完整标记可指定 Eye 的关注目标。喷泉伏击和桶诱敌共用这条规则。第一关不要再叠加五种颜色对应五种能力。
- **再做“补画”。**Eye 显示草图，玩家喷涂后让一块平台在移开目光后多保持几秒。限制为预制草图和一两块可保持的平台，不做任意生成几何体。这样借 Eye 给物体仍有价值。
- **让“擦除”影响路线。**Grub 擦掉临时标记，Host 就失去目标；擦掉补画的平台前，应先出现明显的缺角或滴落警告。首个教学区域不要同时出现擦除敌人。
- **让“签名”保存玩家的贡献。**唤醒建筑后，让玩家在低细节区域喷自己的图案，结尾保留或展示。奖励看覆盖不同区域，而不是原地按住喷漆刷次数；不要要求精准手绘识别。

还需要解决三个实际手感问题：

- 目前每次重新按下喷漆都会换色。自由涂鸦需要锁定颜色，并提供单独的换色操作。
- 含着东西时左键会变成吐射。至少要明显显示嘴中弹药，并让普通喷涂仍然可预测。
- 瞄准射线检查 60 米，但液滴受寿命和阻力限制，实际喷程短得多。标称初速的理想水平积分约为 **6.6 米**，不是可靠的远射武器。准星应提示“够不到”，首场战斗应围绕近距离喷涂设计。[喷漆规则](<local-path>)

玩法笔迹必须有独立状态。目前 2,400 个 stamp 使用循环覆盖：所有液滴都落在场景时，约 52 秒累计喷涂即可用完整个池。平台是否存在、标记是否有效，不能跟着视觉缓存回收而消失。移动箱子上的标记也必须跟随箱子，不能留在世界原位置。[笔迹实现](<local-path>)

**2. 品味自检**

目前最急的不是再加互动，而是让已有互动值得相信。

- **“跟随”存在明确的方向错误。**`OrganHost.ts:379` 先执行 `to.normalize()`，随后再读取 `to.length()`，得到的是 1。普通中型 Host 的速度倍率因此算成约 **-2.89 m/s**，小型约 **-0.54 m/s**。没有食物目标时，它们会朝相反方向移动。玩家会把这个错误当成器官规则，而不是代码问题。先保存原始距离，再归一化。[具体表达式](<local-path>)
- **眼睛表现必须等于视线规则。**小物体的瞳孔会看着 WAI，但实际 `gazer()` 使用 Host 朝向。玩家无法知道它究竟在看玩家还是桥。显示一致的瞳孔方向、短视线提示和受影响平台。
- **吞食必须表现为世界里的动作。**当前嘴按距离查询，Eye 不参与判断，也没有统一遮挡检查。不能让嘴隔墙吞食，却要求 Eye 遵守墙体遮挡。
- **失败反应应帮助下一次尝试。**“太重，走不动”值得保留；只有一句俏皮话却看不出下一步，不足以支持多次试验。
- **非致命设定要由结果表达。**大怪已经有重涂与平静状态。Grub 被喷或吞后直接爆粒子消失，仍容易被读成击杀。让它被吐成干净的小居民、逃走或参与短暂庆祝，成本比新战斗系统低。
- **美术应保留可操作区域的安静。**参考图处处有皇冠、眼睛、嘴和高饱和笔触。可拾取皇冠需要独有轮廓与动效；互动器官需要统一材质；可喷区域需要较低细节背景。否则新增笔迹看不出来，功能物体也会淹没在装饰里。

首关不应以“几乎所有物体都接受三种器官”为完成标准。更有价值的标准是：**玩家在三个不同地方，成功复用同一条规则，并愿意主动尝试第四次。**
