# Sound effect credits

All recorded sounds in this folder come from packs by **Kenney** (https://kenney.nl), released under **CC0 1.0 Universal** (public domain). No attribution is required; this file is a courtesy.

| Pack | Page |
|---|---|
| Impact Sounds | https://kenney.nl/assets/impact-sounds |
| Interface Sounds | https://kenney.nl/assets/interface-sounds |
| RPG Audio | https://kenney.nl/assets/rpg-audio |
| Music Jingles | https://kenney.nl/assets/music-jingles |
| UI Audio | https://kenney.nl/assets/ui-audio |
| Digital Audio | https://kenney.nl/assets/digital-audio |

The files were trimmed (leading silence), converted to mono MP3 and peak-normalized. `manifest.json` maps each game sound to its variations, its volume, and whether the game's synth recipe plays on top (`layer`).
