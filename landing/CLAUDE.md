# landing/
> L2 | 父级: ../AGENTS.md

游戏网站的落地页：在线玩、各平台入口、GitHub 源码、反馈入口。纯静态，上线不需要构建（伙伴的打包产物已入库）。

成员清单
index.html: 整个页面。样式沿用品牌图的色板（墨、纸、粉、黄、钴蓝、青、橙）、半调网点底、墨色粗边框和硬阴影。所有外部地址写在文件末尾的 `LINKS` 一处。动效只是装饰：片名逐字盖下、红线画出、各段滚动到时进场、左侧一条铅笔线跟着滚动走；系统开了“减少动态效果”或脚本不可用时，页面静止且内容完整。
buddy.js: 页面伙伴的成品文件（含用到的 three.js 部分），由 `src/buddy.js` 打包而来并入库。页面加载完才去取它；取不到页面照常。
src/buddy.js: 页面伙伴的源码。游戏里的主角模型站在页面底角：换段落时走到另一边，滚动时原地走，朝指针转身，说这一段的台词，被点时跳一下。模型的手臂默认垂在方形身体里，从正面看不到手；每帧在动画之上把上臂向两侧张开（`SPREAD`），只在页面里这么做，游戏不变。各段落用 `data-buddy`（站哪边）、`data-say`（台词，竖线分隔）、`data-act`（进场动作）告诉他。
vite.buddy.config.mjs: 打包伙伴的配置。改了 `src/buddy.js` 后跑 `npx vite build --config landing/vite.buddy.config.mjs`。
assets/: 主角模型 `wai.glb`（游戏 `public/models/wai2.glb` 的副本）、主角和大肥鱼的渲染图（取自品牌图组）、三关的卡片（取自 `public/assets/levels/`）、四张游戏截图（取自介绍视频的引擎素材，没有字幕）。

约定
- 页面放在网站根目录，游戏构建放在旁边的 `play/`。游戏要用相对路径构建（`vite build --base ./`），否则资源地址会指到根目录。
- `LINKS.repo` 指向的仓库公开之前，页面上的 GitHub 按钮对访客是 404。先公开仓库，再上线页面。
- 页面里可以出现给玩家用的商店页链接；后台编号、审核单号、发布记录不写进来。
